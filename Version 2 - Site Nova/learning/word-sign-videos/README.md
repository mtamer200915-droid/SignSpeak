# Signova V2 word sign video guides

This folder contains one named Internet Shortcut (`<word>.url`) for every word class supported by the V2 word model, plus `index.html` as a visual catalog.

The shortcuts open Lifeprint ASL University's lesson page for that sign. The lesson pages include video demonstrations and explanations where available. Videos remain hosted by their publisher; this folder does not copy or redistribute them.

These lessons teach ASL, which can have regional and signer variations. They are learning references, not labeled training footage, and should not be added to the model dataset without checking that the clip matches the project's label definition and license.

Open `index.html` in a browser, then choose a word. Internet access is required.
